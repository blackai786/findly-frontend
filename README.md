# Findly – Smart Lost Item Recovery Platform

Frontend for **Findly**, a MERN-based platform designed to help users recover lost items.

## ✨ Overview

Findly provides a web interface for reporting, searching, and managing lost and found items.

## 🛠️ Tech Stack

- React.js
- JavaScript
- React Router
- Axios
- Vite
- HTML5 & CSS3

## 🚀 Features

- Responsive web interface
- Lost and found item workflows
- User-friendly navigation
- API integration with the backend
- React-based component structure

## 📦 Getting Started

### Prerequisites

- Node.js installed
- npm installed

### Installation

```bash
git clone https://github.com/blackai786/findly-frontend.git
cd findly-frontend
npm install
npm run dev
```
